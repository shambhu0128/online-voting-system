# 🗳️ Online Voting System

An Online Voting System built using **Java, Spring Boot, and MySQL** that allows users to securely cast votes in an online environment.

---

## 🚀 Features

- User registration and login system  
- Admin panel to manage elections and candidates  
- Secure voting functionality  
- One vote per user validation  
- Result display after voting ends  



## 🛠️ Tech Stack

- **Backend:** Java, Spring Boot  
- **Frontend:** HTML, CSS, Thymeleaf  
- **Database:** MySQL  
- **Security:** Spring Security (basic authentication)



## 📂 Project Structure

- `src/main/java` → Backend logic (Controller, Service, Repository)  
- `src/main/resources` → Configuration and templates  
- `application.properties` → Database configuration  


## ▶️ How to Run

1. Clone the repository  
2. Import project into Eclipse/IntelliJ  
3. Configure MySQL database in `application.properties`  
4. Run the Spring Boot application  
5. Open browser and go to `http://localhost:8080`
